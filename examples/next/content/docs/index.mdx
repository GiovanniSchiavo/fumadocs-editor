---
title: Fumadocs Editor Consumer Example
description: A Fumadocs app used to develop and test the editor plugin
---

This example consumes `fumadocs-editor` exactly like a real project would:
the package is a dependency, not a fork of the app.

Open any page and click **Edit this page** to edit MDX source, render a preview,
inspect the diff and submit the change.
