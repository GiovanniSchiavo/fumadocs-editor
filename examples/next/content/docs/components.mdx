## Imported component

import { Since } from "@/components/since";

<Since version="0.1.0" />

The preview ignores the import statement itself and resolves `Since` through
the components registered in `components/mdx.tsx`.

## Component defined in the document

export function Badge({ children }) {
  return <strong>{children}</strong>;
}

<Badge>Defined inline with an export</Badge>

Custom components registered in `components/mdx.tsx` are available both on the
page and in the editor preview.
